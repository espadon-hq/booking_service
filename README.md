# Booking Service

Система онлайн-бронювання готелів.

## Статус проєкту
Поточний стан: **Лабораторна робота №1 (Lab 1)**.
На цьому етапі реалізовано базову архітектуру додатка, визначено структури даних та логіку валідації.

## Основні компоненти
* **Models**: Використання `dataclasses` для опису сутностей (Hotel, Room, Booking).
* **Core**: Реалізація ієрархії власних виключень (Custom Exceptions) для обробки специфічних помилок сервісу.
* **Engine**: Бізнес-логіка для фільтрації готелів, валідації дат та розрахунку вартості проживання.
* **CLI Interface**: Консольна точка входу для взаємодії з користувачем.

## Структура проєкту
```text
booking_service/
├── src/
│   └── booking_service/
│       ├── core/           # Базові виключення
│       ├── models.py       # Структури даних
│       ├── engine.py       # Бізнес-логіка
│       └── main.py         # Точка входу
├── tests/                  # Модульні тести
├── setup.py                # Конфігурація пакета
└── requirements.txt        # Залежності
```
